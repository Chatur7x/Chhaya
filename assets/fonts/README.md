# Inter

Inter variable font from the official Google Fonts source:
https://github.com/google/fonts/tree/main/ofl/inter

Downloaded from Inter[opsz,wght].ttf on 23 October 2026. The accompanying
OFL-Inter.txt is the upstream SIL Open Font License. Bundled locally so the
app does not fetch fonts from a third-party service at runtime.

Roboto Mono is bundled for identity strings under its accompanying SIL Open Font
License, from https://github.com/google/fonts/tree/main/ofl/robotomono.

## Departure Mono

Departure Mono 1.500 by Helena Zhang, downloaded from the official release:
https://github.com/rektdeckard/departure-mono/releases/tag/v1.500

DepartureMono-Regular.otf is bundled for display headings, the wordmark, avatars,
and identity details. OFL-DepartureMono.txt preserves the upstream copyright
and SIL OFL 1.1 license. No network font loading. Inter remains the reading face;
platform fallback handles scripts outside the font character coverage.
